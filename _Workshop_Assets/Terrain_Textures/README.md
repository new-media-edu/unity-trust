# Terrain Textures

Ground textures for the Terrain section of Day 4. Drag this whole folder into your Unity **Project** window.

Each texture comes as two files:

- `*_diff_1k.jpg` - the **Diffuse** (colour) map. This goes in the Terrain Layer's main texture slot.
- `*_nor_gl_1k.jpg` - the **Normal** map. This goes in the Terrain Layer's **Normal Map** slot and gives the ground real surface relief.

| Texture | Good for |
|---|---|
| `grass_004` | A base layer. Lush green lawn grass. |
| `sparse_grass` | A base layer. Dry grass over soil, browner and more muted. |
| `roots` | Forest floor, undergrowth, anything overgrown. |
| `rocky_trail_02` | Paths and worn routes. Paint it where people would walk. |
| `cracked_red_ground` | Dry, arid, desert. Also good for a dried-out riverbed. |

These are **1K** resolution, which is deliberate. Terrain layers tile many times across the ground, so a 1K texture at a Tiling Size of 5 already looks sharp. Higher resolutions would just slow your laptop down.
