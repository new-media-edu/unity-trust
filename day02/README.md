# Day 02: Building the World (Assets & Materials)

**Session Time:** 2.5 Hours

Today we transition from a "greybox" layout to a textured, populated world. We'll focus on importing high-quality assets, mastering materials, and using modular design to build efficiently.

> [!IMPORTANT]
> **Before starting today's session:**
> 1. **Install Polycam on your phone:** Download it from the [iOS App Store](https://apps.apple.com/us/app/polycam-3d-scanner-gltf/id1531533148) or [Google Play Store](https://play.google.com/store/apps/details?id=ai.polycam).
> 2. **Watch the tutorial:** Check out this [Polycam video tutorial](https://www.youtube.com/watch?v=BImnzs-rR_k) to see the photogrammetry capture process in action.

## The Modules

### 1. [Adding Sound](audio.md)
Audio Sources and 3D spatial blend, so sound gets louder as you walk toward it.

### 2. [Making Fire (Particle Systems)](particles.md)
Faking a convincing campfire with Unity's built-in particle system. No shaders, scripts, or downloads. Includes the fix for the magenta-square problem that URP causes. Push it further with **[Advanced Fire](fire-particles-advanced.md)**.

### 3. [Materials, Images & Textures](materials.md)
The heart of today. Dragging images onto surfaces, tiling, metallic and smoothness, transparency, and normal maps. Plus where to find good free textures.

*If you only get through one module today, make it this one. It's the difference between a grey box and a place.*

### 4. [Lighting Teaser](lighting-teaser.md)
A quick tour of the three main light types, just to see what they do. The full lighting pass comes in **[Day 3](../day03/README.md)**.

### 5. [Assets, Prefabs & Environmental Detail](assets-and-prefabs.md)
Importing FBX and GLB models, using the Asset Store, and building efficiently with Prefabs so one edit updates every copy.

### 6. [Photogrammetry](photogrammetry.md)
What Polycam is, and installing the glTFast package so Unity can read the scans. We import them for real in Day 3, so the goal today is having it working before you leave.

## Homework

1. **Polycam Scan:** Use Polycam to scan an object. It can be small or large, but make sure to follow the instructions and know that you might have to scan 2 or 3 things until one works out.
2. **Environment:** Create an environment that has both an indoor and an outdoor element. It's up to you to get as creative or practical with that as you choose. Integrate a photogrammetry scanned object into your scene.
